# Markdown assets

OverSire renders Markdown offline with these files. `build.sh` copies them to `Contents/Resources/markdown`.

| File | Source | License |
|---|---|---|
| `markdown-it.min.js` | markdown-it 14.1.0 | MIT |
| `markdown-it-task-lists.min.js` | markdown-it-task-lists 2.1.1 | ISC |
| `highlight.min.js` | highlight.js 11.10.0, common languages | BSD-3-Clause |
| `github.min.css`, `github-dark.min.css` | highlight.js 11.10.0 styles | BSD-3-Clause |

To update, download the files from `https://cdn.jsdelivr.net/npm/<package>@<version>/` and change the versions here.
